# agent-squared

A recurring problem in large scientific workflows is that an agent's status is surprisingly hard to read from the outside. Even with full visibility into tool calls and traces, you're left inferring progress from raw activity. What we actually want is a clean, explicit status signal that supports fast analytics: is this run progressing, stuck, or done, available now rather than at the end. This repo is a research project exploring two routes to that signal — agentic monitoring, where a second model reads the agent's reasoning stream and classifies its state, and deterministic monitoring, built from cheap computable features. The question we're after is also "what does it cost": how much compute is worth devoting to watching an agent work, how small a monitor model you can get away with, how often it needs to sample, and where cheap deterministic checks hold up.
